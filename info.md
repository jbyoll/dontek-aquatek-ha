# Dontek Aquatek Pool Controller (Unofficial)

Control your **Dontek** pool controller (sold as Aquatek, Theralux Pool+ Manager, Waterco
Pooltek, Aquamate X) from Home Assistant — water temperature, pump mode and variable pump
speed — over the same cloud the official app uses. No extra hardware, no heavy dependencies.

> ⚠️ **Unofficial / community-built.** Not affiliated with or endorsed by Dontek Electronics.
> Reverse-engineered, uses no official API, and may break if Dontek change their cloud.

**Entities:** water temperature sensor · pump status, activity & running-speed sensors ·
pump mode select (Off/On/Auto) · 4-speed selector · per-speed power % numbers ·
all four **Filter Time** schedules (enable / start / end / speed).

**Setup:** add the integration and enter the serial number printed on the controller label
(the long number under the QR code).
